📝 ÉNONCÉ

Complète chaque phrase avec la bonne commande npm :

npm ______   → installe le projet sur la machine
npm ______   → démarre le projet
npm ______   → lance les tests du projet
npm run ____ → lance un environnement de développement

SOlustion : 

npm install   → installe le projet sur la machine
npm start → démarre le projet
npm test   → lance les tests du projet
npm run dev → lance un environnement de développement
