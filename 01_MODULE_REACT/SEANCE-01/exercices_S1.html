🟢 NIVEAU 1 — Fondamentaux

🧠 À savoir avant de commencer

  • Front-end = HTML/CSS/JS côté navigateur ; back-end = serveur + base de données.
  • Un framework front-end applicatif (React, Angular, Vue) sert à construire l'interface ; un framework back-end (Node, Laravel, Django...) communique avec la BDD.
  • Une classe ES6 se déclare avec class ; ses attributs se fixent dans constructor() via this.
  • Le template literal utilise les backticks `...${var}...`.
  • L'opérateur ternaire : condition ? valeurSiVrai : valeurSiFaux.

EXERCICE 1 — Front-end ou back-end ? [Exercice d'entraînement]

🟢 Niveau 1
Notions : front-end / back-end / rôle du serveur
🎯 Objectif : distinguer clairement ce qui relève du front-end et du back-end dans un scénario e-commerce.

📝 Énoncé

Un client parcourt un site de vente de chaussures, ajoute un article au panier, valide sa commande, puis revient deux jours plus tard consulter l'état de sa livraison.

✅ À toi de jouer

  1. Lister les actions de ce scénario qui relèvent du front-end.
  2. Lister les actions qui relèvent du back-end.
  3. Expliquer avec tes mots à quel moment les données passent du front-end au back-end.
💡 Indice
Demande-toi : est-ce que l'action se voit à l'écran (interface) ou est-ce qu'elle touche à une donnée stockée quelque part ?
🧠 Astuce
Le front-end est ce que l'utilisateur voit et manipule ; dès qu'une information doit être conservée, vérifiée ou récupérée plus tard, c'est le back-end qui entre en jeu.
✅ Corrigé + Explication

1. Analyse : le scénario contient une phase d'interaction visuelle et une phase de persistance/traitement de données.

2. Front-end : parcourir les chaussures, cliquer sur "ajouter au panier", voir le panier, cliquer sur "valider la commande", consulter la page de suivi.

3. Back-end : enregistrer l'article dans le panier en base de données, autoriser le paiement, mettre à jour le statut de livraison, renvoyer les données de suivi.

4. Le passage front → back se fait à chaque fois que l'utilisateur envoie une donnée (clic "ajouter au panier", clic "valider") : le front-end transmet la demande au serveur, qui la traite et répond.

EXERCICE 3 — Ma première classe ES6 [Exercice d'entraînement]

🟢 Niveau 1
Notions : class, constructor, this, instanciation
🎯 Objectif : écrire une classe ES6 simple et créer des instances.

📝 Énoncé

On veut modéliser un Livre avec un titre et un auteur.

✅ À toi de jouer

  1. Déclarer une classe Livre avec un constructeur (titre, auteur).
  2. Créer deux instances : livre1 ("1984", "Orwell") et livre2 ("Dune", "Herbert").
  3. Afficher livre1.titre dans la console.
💡 Indice
Reviens à l'exemple Etudiant du cours : les paramètres du constructeur se mémorisent avec this.propriete = parametre.
🧠 Astuce
Erreur fréquente : oublier la majuscule au nom de la classe, ou écrire this.titre=titre sans respecter la casse du paramètre.
✅ Corrigé

1. Analyse : deux attributs, aucune méthode requise pour l'instant.

2. Implémentation :

class Livre{
  constructor(titre, auteur){
    this.titre = titre;
    this.auteur = auteur;
  }
}
let livre1 = new Livre("1984", "Orwell");
let livre2 = new Livre("Dune", "Herbert");
console.log(livre1.titre);

3. Résultat attendu : 1984 affiché dans la console.

Ce qu'on fait : on définit un modèle (classe) réutilisable.
Pourquoi : pour créer plusieurs objets Livre sans réécrire la structure.
Résultat : deux objets indépendants, chacun avec ses propres valeurs.

EXERCICE 7 — Héritage : du Produit au ProduitSolde [Exercice d'entraînement]

🟡 Niveau 2
Notions : extends, super, redéfinition de méthode
🎯 Objectif : créer une classe dérivée qui enrichit une classe existante.

📝 Énoncé

On dispose d'une classe Produit avec nom et prix, et une méthode info() qui retourne "Produit nom:X a pour prix:Y".

✅ À toi de jouer

  1. Écrire la classe Produit avec son constructeur et sa méthode info().
  2. Créer une classe ProduitSolde extends Produit qui ajoute un attribut remise (en %).
  3. Redéfinir info() dans ProduitSolde pour qu'elle réutilise super.info() et ajoute la remise.
  4. Créer une instance et afficher son info().
💡 Indice
Regarde l'exemple Stagiaire extends Etudiant du cours : même logique avec super(nom, prix).
🧠 Astuce
Piège fréquent : oublier d'appeler super(...) avant d'utiliser this dans le constructeur de la classe fille — cela provoque une erreur.
✅ Corrigé + Solution + Explication 
class Produit{
  constructor(nom, prix){
    this.nom = nom;
    this.prix = prix;
  }
  info(){
    return `Produit nom:${this.nom} a pour prix:${this.prix}`;
  }
}
class ProduitSolde extends Produit{
  constructor(nom, prix, remise){
    super(nom, prix);
    this.remise = remise;
  }
  info(){
    return `${super.info()} remise:${this.remise}%`;
  }
}
let p1 = new ProduitSolde("Sac", 200, 30);
console.log(p1.info());
// Produit nom:Sac a pour prix:200 remise:30%
super(nom, prix) : appelle le constructeur de Produit pour initialiser nom et prix avant d'ajouter remise.
super.info() : réutilise le texte déjà généré par la classe mère au lieu de le réécrire.

🧠 À savoir avant de commencer

EXERCICE 15 — Récursivité : puissance [Exercice d'entraînement]

🟠 Niveau 3
Notions : récursivité, cas d'arrêt
🎯 Objectif : écrire une fonction récursive avec un cas de base correct.

📝 Énoncé

On veut calculer base élevé à la puissance exposant (entiers positifs), sans utiliser Math.pow ni **.

✅ À toi de jouer

  1. Écrire une fonction récursive puissance(base, exposant).
  2. Définir le cas d'arrêt (quand exposant === 0).
  3. Tester avec puissance(2, 5).
💡 Indice
Inspire-toi de fact(n) du cours : le cas d'arrêt retourne une valeur fixe, sinon on multiplie par un appel récursif avec un exposant réduit de 1.
🧠 Astuce
Piège fréquent : oublier le cas d'arrêt provoque une boucle infinie (stack overflow).
✅ Corrigé + Explication 
function puissance(base, exposant){
  if(exposant === 0){
    return 1;
  }
  return base * puissance(base, exposant - 1);
}
console.log(puissance(2, 5)); // 32
Chaque appel réduit le problème (l'exposant diminue de 1) jusqu'à atteindre le cas d'arrêt, puis les résultats "remontent" en se multipliant.

EXERCICE 16 — Closure : jauge de points [Exercice d'entraînement]

🟠 Niveau 3
Notions : closures, variables privées
🎯 Objectif : utiliser une fermeture pour garder une variable "privée" entre plusieurs appels.

📝 Énoncé

On veut une fonction creerJauge(depart) qui retourne une fonction permettant d'ajouter des points à chaque appel, en gardant le score en mémoire.

✅ À toi de jouer

  1. Écrire creerJauge(depart) qui retourne une fonction acceptant un paramètre points.
  2. Chaque appel de la fonction retournée doit ajouter points au score et le retourner.
  3. Tester : let jauge = creerJauge(10); jauge(5); jauge(3);
💡 Indice
Reprends la structure de compteur() du cours : une variable déclarée dans la fonction externe, modifiée par la fonction interne retournée.
🧠 Astuce
Vérification : chaque appel à creerJauge() crée une nouvelle closure indépendante — deux jauges différentes n'interfèrent pas.
✅ Corrigé + Explication

  let score = depart;
  return function(points){
    score += points;
    return score;
  };
}

console.log(jauge(5)); // 15
console.log(jauge(3)); // 18
La fonction interne "se souvient" de score grâce à la fermeture, même après la fin de l'exécution de creerJauge.
