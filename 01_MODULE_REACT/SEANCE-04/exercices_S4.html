NIVEAU 1

Fondamentaux

★☆☆☆☆
📌 À savoir avant de commencer
  • JSX permet d'écrire des éléments React avec une syntaxe proche du HTML, à l'intérieur du code JavaScript.
  • Une balise commençant par une minuscule (div, p, ul, li...) est un élément HTML connu de React DOM.
  • Une balise commençant par une majuscule doit correspondre à un élément déjà déclaré (fonction, composant importé...).
  • Le code JSX doit être interprété par Babel avant d'être compris par le navigateur (balise &lt;script type="text/babel"&gt;).
  • ReactDOM.render(élément, cible) affiche un élément React dans la page HTML.
  • class devient className en JSX, car class est un mot réservé en JavaScript.

NIVEAU 2

Application

★★☆☆☆
📌 À savoir avant de commencer
  • L'attribut style en JSX attend un objet JavaScript : style={{ propriete: valeur }} (double accolade).
  • Les propriétés CSS composées s'écrivent en camelCase en JSX (list-style-type devient listStyleType).
  • Toute expression JavaScript insérée dans du JSX doit être entourée d'une seule accolade { }.
  • La méthode .map() permet de transformer chaque élément d'un tableau en élément JSX.
  • Chaque élément généré dans une boucle (map) doit posséder un attribut key unique.
  • La notation fléchée ES6 (elem, index) => ... peut remplacer function(elem, index) { return ... }.

var eleves = [
  { nom: "Yassine", moyenne: 8 },
  { nom: "Imane", moyenne: 14 },
  { nom: "Othmane", moyenne: 17 }
];

function getMention(moyenne) {
  if (moyenne < 10) { return { texte: "Insuffisant", couleur: "red" }; }
  if (moyenne < 14) { return { texte: "Passable", couleur: "orange" }; }
  return { texte: "Bien", couleur: "green" };
}

function LigneEleve({ eleve }) {
  var mention = getMention(eleve.moyenne);
  return (
    <p>
      {eleve.nom} — {eleve.moyenne}/20 —
      <span style={{ color: mention.couleur, fontWeight: "bold" }}> {mention.texte}</span>
    </p>
  );
}

function Bulletin({ eleves }) {
  return (
    <div>
      { eleves.map((e, index) => <LigneEleve key={index} eleve={e} />) }
    </div>
  );
}

ReactDOM.render(<Bulletin eleves={eleves} />, document.getElementById("app"));
