Niveau 5 — Préparation intensive au contrôle

Cette banque contient 18 exercices de difficulté progressive (de ★ à ★★★★★) et un mini-contrôle blanc sur 20 points, tous basés sur ton cours « S4 : Le langage JSX » (OFPPT – DRIF, C12 Développer en Front-end, 16 pages).

Méthode de travail conseillée
  1. Lis l'énoncé et cherche seule, sur papier ou dans ton éditeur, sans regarder le corrigé.
  2. Si tu bloques, ouvre l'Indice, puis l'Astuce.
  3. Une fois ta solution écrite, ouvre le corrigé (Partie 2) et compare. Dans les corrigés, le bouton ▶ Exécuter affiche le résultat directement (connexion Internet requise : React et Babel sont chargés depuis unpkg).
  4. Mets à jour ton statut : ☐ À faire · ☐ Terminé · ☐ À revoir. Il est sauvegardé dans ton navigateur.
  5. Termine par le mini-contrôle en conditions réelles (chronomètre intégré).

À savoir (informations manquantes ou hors cours) :
  • Ton PDF ne contient aucun exercice ni sujet de contrôle : tous les exercices ici sont originaux.
  • Je n'ai trouvé aucun ancien contrôle OFPPT ou EFM sur React exploitable sur le Web. Le niveau du contrôle blanc est donc estimé à partir de ton cours et des ressources pédagogiques listées en Partie 5.
  • Le state, les hooks et les événements sont renvoyés au chapitre suivant dans ton cours : ils sont volontairement absents de cette banque.
  • Le cours utilise React 16 et ReactDOM.render(). Dans les versions récentes de React (18 et plus), on utilise ReactDOM.createRoot() : suis la syntaxe de ton cours pour le contrôle.
